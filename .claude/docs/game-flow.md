# ゲームの流れ

来場者 1 人が「開始 → 会話 → 難易度選択 → 1 分間の弾幕 → 結果の会話 → 終了」を体験する。
弾幕まわりの設計は [bullet-system.md](bullet-system.md) を参照。

## 全体の流れ

```text
[開始] ─▶ [オープニング会話] ─▶ [難易度選択] ─▶ [バトル（1 分）] ─▶ [エンディング会話] ─▶ [終了]
          （自動で進む）        （SOUL を 2 秒置く）  （Timeline で弾幕＋会話）  （結果発表）
└──────────── 選択シーン ────────────┘  └──────────────── バトルシーン ────────────────┘
```

## 各ステップ

### 1. 開始

- ユーザーがゲームを開始する。

### 2. オープニング会話（自動で進む）

- 敵キャラが話しかける。ボタン操作なしで、一定時間ごとに次のセリフへ進む。
- 例:
  1. 「今日は来てくれてありがとう。」
  2. 「難易度を選んでね」
- 会話が終わったら難易度選択に移る。

### 3. 難易度選択（SOUL を置いて選ぶ）

- 画面に **Easy / Medium / Hard** の 3 つの選択肢が並ぶ。
- SOUL（LiDAR またはキーボードで操作）を選択肢の上に **2 秒間** 置き続けると、その難易度に決まる。
  - 途中で選択肢から外れたら、時間はリセットする。
  - 残り時間がわかる表示（ゲージなど）を出す。
- 決まったらバトルシーンへ移る。

### 4. バトル開始（シーンを切り替える）

- 選んだ難易度に対応する **Timeline** を再生する（難易度ごとに 1 本ずつ用意する）。
- Timeline には弾幕の発射（`ShotTrack`）に加えて、**敵キャラのセリフ**も並べる。
  バトル中でも決まったタイミングでキャラが喋る。

### 5. バトル（1 分）

- 制限時間は **1 分**。弾をきれいに避け続けるゲーム。
- HP によるゲームオーバーは無い。被弾しても最後まで続ける（被弾後は一定時間無敵）。
- SOUL の操作は **LiDAR** と **キーボード** のどちらでもできるようにする。

### 6. エンディング会話 → 終了

- 1 分経ったら弾幕を止め、敵キャラが喋り出す。
- 例:
  1. 「ゲームをプレイしてくれてありがとう！」
  2. 「被弾は xxx 回でした」
- 会話が終わったらゲーム終了。

## シーン構成

| シーン | 内容 |
|---|---|
| 選択シーン | 1〜3（開始、オープニング会話、難易度選択） |
| バトルシーン | 4〜6（バトル、エンディング会話、終了） |

- 見た目違いで 2 組ある: 元の版 `SelectScene`/`BattleScene` と、スキャナー版 `ScannerSelectScene`/`ScannerBattleScene`。
  流れ・弾幕は同じで、各組の中だけで遷移する。

- 選んだ難易度は、シーンをまたいで引き継ぐ。
- SOUL・入力・会話表示は両方のシーンで使う。

## 難易度

- Easy / Medium / Hard は **同じ仕組みで、Timeline（弾の数・速さ・発射間隔など）だけが違う**。
- 難易度ごとに Timeline を 4 本用意し、毎回ランダムに 1 本選ぶ（列に並んでいる人が前のプレイを見て攻略を覚えないように。前回と同じものは避ける）。
  1 本の中の乱数はシード固定なので、同じ Timeline なら毎回同じ弾幕になる。どれを選んだかは記録（`plays.jsonl` の `timeline`）に残る。

## 決まっていないこと

- **入力の切り替え**: LiDAR とキーボードを同時に有効にするか、どちらか一方を選ぶか。
  LiDAR がハートを見失ったときに、キーボードへ自動で切り替えるか。
- **開始の操作**: 何をしたら「開始」になるか（キー入力、SOUL を置く、など）。
- **終了後**: 最初（選択シーン）に自動で戻るか、止まったままにするか。展示で連続プレイするなら、自動で戻る方がよい。
- **会話の送り速度**: 1 セリフあたりの表示時間。文字送り（1 文字ずつ表示）にするか。

## 実装（最低限版）

| ステップ | 担当 | 今の動き |
|---|---|---|
| 1. 開始 | — | 選択シーンを開いたら即開始（開始操作は未実装） |
| 2. オープニング会話 | `SelectFlow` + `DialogueBox.PlayAuto` | 1 行ずつ自動で送る |
| 3. 難易度選択 | `DifficultyOption` ×3 | SOUL を 2 秒置くと決定。ゲージ表示あり。`GameSession` に保存 |
| 4〜5. バトル | `BattleFlow` | 難易度の Timeline の候補（`Assets/Timelines/Battle/Easy1〜4` など）からランダムに 1 本再生。セリフは `DialogueTrack`。右上に残り秒数（スキャナー版は左上でバー付き）。元の版は左下に今の難易度（被弾回数はドキドキ感のためプレイ中は出さない） |
| 6. エンディング | `BattleFlow` | 60 秒で弾を消し、会話で被弾回数を出して選択シーンへ戻る |

- スコアは出さない。結果は被弾回数だけ（`ScoreKeeper` が数える）。グレイズは点にしない。
  エンディングの会話で「被弾は ○ 回でした」と出す。
- Timeline のトラックのバインドは `BattleFlow` が種類を見て自動で設定する（Timeline 側での設定は不要）。

## 立ち絵

会話ボックスのすぐ左に敵キャラの立ち絵を出す（`PortraitView`）。会話ボックスは横幅を画面の 35〜80% に狭めて左を空け、
立ち絵は上端を会話ボックスにそろえて画面の上半分に収める（縦は画面の割合で決めるので 16:9 以外でもはみ出さない）。アニメーションではなく、静止画を表情ごとに差し替える。

- 表情は 5 種（`PortraitExpression`）: `Base`（ベース）/ `Talk`（口をあけている）/ `Attack`（技を出している）/
  `Smile`（笑顔）/ `Defeat`（負け顔）。
- 素材は難易度ごとに別。`Assets/Settings/Portraits/{Easy,Medium,Hard}.asset`（`PortraitSet`）に表情ごとの画像を割り当てる。
  画像は `Assets/Art/Portraits/<難易度>/<表情名>.png`（例: `Easy/Talk.png`、Texture Type は Sprite）。
  今は動作確認用の仮の画像（「仮 Easy / 口あけ」などと書いた簡単な顔）が入っていて、割り当ても済んでいる。
  本番素材は同じファイル名で上書きすれば、割り当てをやり直さずに差し替わる。
  未設定の表情はベースで代用し、ベースも無いときは配置確認用の半透明の枠を出す。
- `Rebuild Game Setup` は `PortraitSet` を無いときだけ作る（割り当てた画像は作り直しで消えない）。

| 場面 | どの表情か | 決めているところ |
|---|---|---|
| 選択シーン | Easy のベース | シーンの `PortraitView._set` |
| バトル中 | Timeline の `PortraitTrack` に置いた `PortraitClip` の表情。クリップの無いところはベース | 難易度の Timeline |
| エンディング会話 | 負け顔 | `BattleFlow._endingExpression` |

- バトル中の切り替えは Timeline で編集する。`Portrait` トラックにクリップを置き、Inspector で表情を選ぶ
  （クリップ名は表情名に自動でそろう）。バインドは `BattleFlow` が自動で設定する。
- `Rebuild Game Setup` の初期配置: セリフの間は `Talk`（一部 `Smile`）、弾幕が切り替わる直後の 2 秒は `Attack`。

### 立ち絵の動き

- `PortraitMotionTrack` に `PortraitMotionClip` を置くと、その間だけ立ち絵が元の位置のまわりで動く。
  動き方は `Float`（ふわふわ上下）/ `Sway`（左右に往復）/ `Shake`（小刻みに震える）で、幅（px）と速さ（Hz）を Inspector で決める。
- トラックを複数置くと動きは足し合わされる。同じトラックで重ねると足し合わずにクロスフェードになるので、重ねたい動きは別トラックにする。
  クリップに Ease In/Out を付けると、動きが滑らかに始まる・終わる。
- 時間はクリップ内の時間なので、一時停止中は止まる。クリップの無いところでは元の位置に戻る。
- `Rebuild Game Setup` の初期配置（全難易度共通）: 後半（30〜60 秒）は `Portrait Motion` トラックで `Float`（幅 12px・0.5Hz、Ease In 1 秒）。
  `Attack` の顔の間は `Portrait Shake` トラックで `Shake`（幅 6px）。
