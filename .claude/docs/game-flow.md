# ゲームの流れ

来場者 1 人が「開始 → 会話 → 難易度選択 → 1 分間の弾幕 → 結果の会話 → 終了」を体験する。
弾幕まわりの設計は [bullet-system.md](bullet-system.md) を参照。

## 全体の流れ

```text
[開始] ─▶ [オープニング会話] ─▶ [難易度選択] ─▶ [バトル（1 分）] ─▶ [エンディング会話] ─▶ [終了]
          （自動で進む）        （SOUL を 2 秒置く）  （Timeline で弾幕＋会話）  （スコア発表）
└──────────── 選択シーン ────────────┘  └──────────────── バトルシーン ────────────────┘
```

## 各ステップ

### 1. 開始

- ユーザーがゲームを開始する。

### 2. オープニング会話（自動で進む）

- 敵キャラが話しかける。ボタン操作なしで、一定時間ごとに次のセリフへ進む。
- 例:
  1. 「今日は来てくれてありがとう。」
  2. 「難易度を選んでね」
- 会話が終わったら難易度選択に移る。

### 3. 難易度選択（SOUL を置いて選ぶ）

- 画面に **Easy / Medium / Hard** の 3 つの選択肢が並ぶ。
- SOUL（LiDAR またはキーボードで操作）を選択肢の上に **2 秒間** 置き続けると、その難易度に決まる。
  - 途中で選択肢から外れたら、時間はリセットする。
  - 残り時間がわかる表示（ゲージなど）を出す。
- 決まったらバトルシーンへ移る。

### 4. バトル開始（シーンを切り替える）

- 選んだ難易度に対応する **Timeline** を再生する（難易度ごとに 1 本ずつ用意する）。
- Timeline には弾幕の発射（`ShotTrack`）に加えて、**敵キャラのセリフ**も並べる。
  バトル中でも決まったタイミングでキャラが喋る。

### 5. バトル（1 分）

- 制限時間は **1 分**。弾をきれいに避け続けるゲーム。
- HP によるゲームオーバーは無い。被弾しても最後まで続ける（被弾後は一定時間無敵）。
- SOUL の操作は **LiDAR** と **キーボード** のどちらでもできるようにする。

### 6. エンディング会話 → 終了

- 1 分経ったら弾幕を止め、敵キャラが喋り出す。
- 例:
  1. 「ゲームをプレイしてくれてありがとう！」
  2. 「スコアは xxx でした」
- 会話が終わったらゲーム終了。

## シーン構成

| シーン | 内容 |
|---|---|
| 選択シーン | 1〜3（開始、オープニング会話、難易度選択） |
| バトルシーン | 4〜6（バトル、エンディング会話、終了） |

- 選んだ難易度は、シーンをまたいで引き継ぐ。
- SOUL・入力・会話表示は両方のシーンで使う。

## 難易度

- Easy / Medium / Hard は **同じ仕組みで、Timeline（弾の数・速さ・発射間隔など）だけが違う**。
- 来場者どうしでスコアを比べるため、同じ難易度なら毎回同じ弾幕にする（乱数シード固定）。

## 決まっていないこと

- **スコアの計算方法**: 被弾数・グレイズ数から出す想定だが、式は未定。難易度による倍率を付けるかも未定。
- **入力の切り替え**: LiDAR とキーボードを同時に有効にするか、どちらか一方を選ぶか。
  LiDAR がハートを見失ったときに、キーボードへ自動で切り替えるか。
- **開始の操作**: 何をしたら「開始」になるか（キー入力、SOUL を置く、など）。
- **終了後**: 最初（選択シーン）に自動で戻るか、止まったままにするか。展示で連続プレイするなら、自動で戻る方がよい。
- **会話の送り速度**: 1 セリフあたりの表示時間。文字送り（1 文字ずつ表示）にするか。

## 実装（最低限版）

| ステップ | 担当 | 今の動き |
|---|---|---|
| 1. 開始 | — | 選択シーンを開いたら即開始（開始操作は未実装） |
| 2. オープニング会話 | `SelectFlow` + `DialogueBox.PlayAuto` | 1 行ずつ自動で送る |
| 3. 難易度選択 | `DifficultyOption` ×3 | SOUL を 2 秒置くと決定。ゲージ表示あり。`GameSession` に保存 |
| 4〜5. バトル | `BattleFlow` | 難易度の Timeline（`Assets/Timelines/Easy/Medium/Hard`）を再生。セリフは `DialogueTrack`。右上の HUD にスコア・被弾・グレイズと残り時間バー |
| 6. エンディング | `BattleFlow` | 60 秒で弾を消し、会話でスコアを出して選択シーンへ戻る |

- 入力は今はキーボードのみ。スコアは `ScoreKeeper` の仮の式（1000 − 被弾×100 ＋ グレイズ×10）。
- Timeline のトラックのバインドは `BattleFlow` が種類を見て自動で設定する（Timeline 側での設定は不要）。
